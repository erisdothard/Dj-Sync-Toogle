Add to the iOS share sheet (one-time)
  1. Open Shortcuts → + → name it DJ Sync.
  2. Tap the ⓘ info button → turn on Show in Share Sheet → Done.
  3. Add action Choose from Menu. Prompt: Sync how? Options: Auto-sync and Review first.
  4. Inside the Auto-sync branch add Open URLs with and insert the Shortcut Input variable right after the =.
  5. Inside the Review first branch add Open URLs with and insert Shortcut Input the same way.
  6. Done. In YouTube: Share → More → DJ Sync → pick Auto-sync or Review first.

Skip the menu if you prefer: one Open URLs with uses the switch on this page.
